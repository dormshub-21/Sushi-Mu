# Gestor de Ventas - Sushi

Sistema web para gestión de ventas, productos, pedidos, caja y usuarios de un restaurante de sushi.

## Stack

- Frontend: React + Vite
- Backend: Node.js + Express
- Base de datos: PostgreSQL en Render
- Deploy: Render

## Estructura

- `/frontend`: interfaz del sistema
- `/backend`: API y lógica del servidor
- `/database`: scripts SQL, migraciones y seeds
- `/docs`: documentación y capturas
- `/scripts`: scripts auxiliares
